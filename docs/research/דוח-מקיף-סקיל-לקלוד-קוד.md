## חלק 1: Claude Code Skills – מחקר מעמיק

### 1.1 הגדרה רשמית של Skills (Anthropic)

לפי ההגדרה הרשמית של Anthropic ב-`code.claude.com/docs/en/skills` ובבלוג ההנדסי "Equipping agents for the real world with Agent Skills" (אוקטובר 2025, פתוח כסטנדרט פתוח ב-18 בדצמבר 2025):

> *"Skills are folders of instructions, scripts, and resources that Claude loads dynamically to improve performance on specialized tasks."*

Skill **אינו** קובץ Markdown בודד – זו **תיקייה** שיכולה להכיל:
- `SKILL.md` (חובה) – ההוראות והמטא-דאטה
- `scripts/` – קוד הרצה דטרמיניסטי (Python, Node, Bash)
- `references/` – תיעוד נוסף שנטען לפי דרישה
- `assets/` – תבניות, פונטים, אייקונים, תמונות

Skills זמינים בכל מוצרי Claude: Claude Code, Claude.ai, ו-Claude API. **באותו פורמט בדיוק** – אותו skill עובד בכל מקום.

### 1.2 מבנה SKILL.md – מפרט מלא

קובץ SKILL.md מתחיל ב-YAML frontmatter ואחריו תוכן Markdown:

```yaml
---
name: my-skill-name
description: What this skill does AND when to use it. Trigger when user mentions X, Y, Z, even if they don't explicitly ask.
disable-model-invocation: false   # optional, default false
allowed-tools: Read, Grep, Bash   # optional, restricts tools
---

# Instructions

Your detailed instructions in Markdown here.

## When to use

## Steps

## Gotchas
- Common mistake 1
- Common mistake 2
```

**שדות חובה:** `name`, `description`. השאר אופציונלי.

**מיקומים (הכי חשוב):**
- `~/.claude/skills/<skill-name>/SKILL.md` – משתמש (זמין בכל פרויקט)
- `.claude/skills/<skill-name>/SKILL.md` – פרויקט (משותף בריפו)
- ניתן להוסיף דרך `--add-dir` – Claude Code יטען `.claude/skills/` מתוך התיקייה הנוספת אוטומטית

**הגבלת אורך:** Anthropic ממליצה לשמור על SKILL.md מתחת ל-5,000 מילים. תוכן ארוך עובר ל-`references/` ונטען לפי דרישה.

### 1.3 ההבדל בין Skills, Subagents ו-Slash Commands

| מימד | **Skill** | **Subagent** | **Slash Command** |
|---|---|---|---|
| **הפעלה** | אוטומטית לפי `description` | על ידי Claude לפי `description` או בקריאה מפורשת | המשתמש מקליד `/name` |
| **קונטקסט** | נטען לתוך השיחה הראשית | חלון קונטקסט נפרד, מבודד | רץ בקונטקסט הראשי |
| **מטרה** | ידע פרוצדורלי + קבצי עזר | משימת משנה ארוכה שתציף את הקונטקסט הראשי | פעולה חד-פעמית מהירה |
| **מבנה** | תיקייה עם `SKILL.md` + scripts | קובץ `.md` ב-`.claude/agents/` | קובץ `.md` ב-`.claude/commands/` |
| **מתי לבחור** | סטנדרטים, מתודולוגיות, תבניות חוזרות | מחקר עומק, refactor רחב, ניתוח עם הרבה פלט | פעולה מהירה ויזומה |

**כלל אצבע (מה-docs הרשמי):**
> *"Use subagents when the task produces verbose output you don't need in your main context. Consider Skills instead when you want reusable prompts or workflows that run in the main conversation context."*

עבור Baby Mania – רוב מה שתבנה צריך להיות **Skills** (אוטומציה של כתיבת sections, content בעברית, schema markup). Subagents מועילים למשימות כמו "סרוק את כל ה-product pages וחפש בעיות SEO".

### 1.4 Progressive Disclosure – המנגנון שמפעיל Skills

זהו עקרון העיצוב המרכזי של Skills (לפי הבלוג הרשמי של Anthropic):

**שלוש רמות טעינה:**

1. **רמה 1 – Metadata (טוען בהפעלה):** רק `name` ו-`description` של כל Skill מותקן נטענים ל-system prompt. עלות: ~100 tokens לכל Skill.
2. **רמה 2 – SKILL.md body (טוען בעת רלוונטיות):** כש-Claude מזהה משימה התואמת ל-description, הוא קורא את כל גוף ה-SKILL.md.
3. **רמה 3 – Supporting files (טוען לפי דרישה):** רק כש-SKILL.md מפנה לקובץ ב-`references/` או מריץ `scripts/`.

**משמעות מעשית:** ניתן להתקין עשרות Skills מבלי לפוצץ את הקונטקסט. מה שחשוב זה ש-`description` יהיה מדויק.

### 1.7 Best Practices לכתיבת Skill (לפי Anthropic engineering)

**ה-`description` הוא הכל.** הוא הטריגר היחיד. הנחיות מתוך skill-creator הרשמי:

> *"Claude has a tendency to 'undertrigger' skills. Make the skill descriptions a little bit 'pushy'."*

**דוגמה גרועה:**
```yaml
description: How to build a dashboard.
```

**דוגמה טובה:**
```yaml
description: How to build a fast Hebrew RTL dashboard for Shopify. Make sure to use this skill whenever the user mentions dashboard, dashboards, data visualization, internal metrics, RTL admin pages, or wants to display any kind of company data in Hebrew, even if they don't explicitly ask for a 'dashboard.'
```

**עקרונות מפתח:**
1. **Structure:** מה זה עושה + מתי להשתמש + יכולות מפתח + ביטויי טריגר
2. **Gotchas section** – החלק החשוב ביותר. עדכן עם בעיות מציאותיות שאתה רואה ב-production.
3. שמור על גוף SKILL.md מתחת ל-5,000 מילים – העבר עומק ל-`references/`.
4. השתמש ב-Scripts לפעולות דטרמיניסטיות (לדוגמה: בדיקת תקינות liquid).
5. אם יש לך MCP server קיים – Skills הם שכבת הידע מעליו, לא תחליף.
6. בדוק את ה-skill עם 5-10 מקרי טריגר אמיתיים לפני שתעלה.

### 2.1 `shopify-rtl-section`

**Trigger description:**
```yaml
description: Build production-ready Shopify Liquid sections for the Hebrew Baby Mania store. Use this skill whenever the user asks to create, modify, or fix a Shopify section, block, snippet, or template. Trigger on mentions of "section", "סקשן", "קומפוננטה", "Liquid", "schema", "RTL", "עברית", baby/תינוק product pages, or any request to add UI to the storefront. Always outputs RTL-compliant Heebo-fontified code.
```

**תוכן עיקרי + קוד:**

```liquid
{% comment %}
  baby-mania-section.liquid
  RTL-first. Heebo. Mobile-first.
{% endcomment %}

<section
  class="bm-section"
  dir="rtl"
  lang="he"
  data-section-id="{{ section.id }}"
  data-section-type="{{ section.settings.section_type }}">
  
  <style>
    .bm-section { 
      font-family: 'Heebo', system-ui, sans-serif;
      direction: rtl;
      text-align: right;
      padding: clamp(24px, 5vw, 64px) 16px;
    }
    .bm-section h2 { 
      font-weight: 700; 
      line-height: 1.2; 
      font-size: clamp(22px, 4vw, 36px); 
    }
    /* CRITICAL: logical properties only - never margin-left/right */
    .bm-section .bm-cta { 
      margin-inline-start: 0; 
      padding-inline: 24px; 
    }
  </style>

  <div class="bm-container">
    <h2>{{ section.settings.heading | escape }}</h2>
    {% if section.settings.subheading != blank %}
      <p>{{ section.settings.subheading }}</p>
    {% endif %}
    
    <a href="{{ section.settings.cta_link }}" class="bm-cta">
      {{ section.settings.cta_text | default: 'לקנייה' }}
    </a>
  </div>
</section>

{% schema %}
{
  "name": "Baby Mania Section",
  "tag": "section",
  "class": "bm-section-wrapper",
  "settings": [
    { "type": "text", "id": "heading", "label": "כותרת", "default": "כותרת בעברית" },
    { "type": "textarea", "id": "subheading", "label": "תת-כותרת" },
    { "type": "text", "id": "cta_text", "label": "טקסט כפתור", "default": "לקנייה" },
    { "type": "url", "id": "cta_link", "label": "קישור כפתור" }
  ],
  "presets": [{ "name": "Baby Mania Section" }]
}
{% endschema %}
```

**Rules ב-SKILL.md:**
- `dir="rtl"` ו-`lang="he"` תמיד.
- שימוש ב-CSS Logical Properties בלבד (`margin-inline-start`, `padding-inline-end`) – לא `left/right`.
- Heebo משוקלל 400/500/700, נטען דרך `theme.liquid` עם `font_picker`.
- `clamp()` לטיפוגרפיה רספונסיבית.
- `{{ ... | escape }}` תמיד עבור user input.
- `data-section-id` חובה לתאימות עם Theme Editor.

**ערך עסקי:** חיסכון של 30-60 דקות per section, אחידות ויזואלית, אפס באגי RTL.

**Trigger description:**
```yaml
description: Generate Hebrew-language SEO content for Baby Mania product pages, collection pages, and blog posts. Use whenever the user mentions SEO, מטא-תיאור, meta description, title tag, alt text, schema markup, structured data, רכישה אורגנית, ranking, Google, or asks to write/rewrite product descriptions. Always outputs Hebrew text + valid JSON-LD schema.
```

**תכולה:**

```liquid
{%- comment -%} JSON-LD for product pages (drop into product.liquid) {%- endcomment -%}
<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": {{ product.title | json }},
  "description": {{ product.description | strip_html | truncate: 5000 | json }},
  "image": [
    {%- for image in product.images limit: 5 -%}
      {{ image | image_url: width: 1200 | prepend: 'https:' | json }}{%- unless forloop.last -%},{%- endunless -%}
    {%- endfor -%}
  ],
  "brand": { "@type": "Brand", "name": "Baby Mania" },
  "sku": {{ product.selected_or_first_available_variant.sku | json }},
  "offers": {
    "@type": "Offer",
    "url": {{ shop.url | append: product.url | json }},
    "priceCurrency": "ILS",
    "price": {{ product.selected_or_first_available_variant.price | divided_by: 100.0 | json }},
    "availability": "{% if product.available %}https://schema.org/InStock{% else %}https://schema.org/OutOfStock{% endif %}",
    "itemCondition": "https://schema.org/NewCondition"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "{{ product.metafields.reviews.rating | default: 4.7 }}",
    "reviewCount": "{{ product.metafields.reviews.count | default: 12 }}"
  }
}
</script>
```

**Content rules:**
- כותרת SEO: 50-60 תווים, מילת מפתח ראשית בתחילה.
- Meta description: 140-155 תווים, כולל CTA.
- alt text לתמונות: תיאור מוצר בעברית + שם המותג.
- מבנה כותרות: H1 יחיד, H2 לקטגוריות, מילות מפתח semantic ב-H2/H3.

**ערך עסקי:** טראפיק אורגני (חינם) ל-Baby Mania, schema = rich snippets = CTR גבוה יותר.

### 2.3 `hebrew-meta-ads-copy`

**Trigger description:**
```yaml
description: Write high-converting Hebrew copy for Meta Ads (Facebook + Instagram) for Baby Mania baby products. Use when user mentions "meta ads", "פייסבוק", "אינסטגרם", "פרסומת", "קופי", "ad copy", "headline", "primary text", or asks to launch/refresh ad creative. Outputs hook + body + CTA in Hebrew with explicit emotion targets (parent worry, FOMO, social proof, scarcity).
```

**תבנית עיקרית:**

```text
# Hook variants (first 125 chars - what shows before "see more")
1. [Pain] "כל ההורים מכירים את זה - השעה 3 לפנות בוקר ו..."
2. [Curiosity] "הסוד שאחיות ב-בית-חולים יודעות על הרגעת תינוקות"
3. [Social proof] "1,847 הורים בישראל כבר גילו את זה החודש"
4. [Question] "התינוק שלך לא נרדם? זה לא בגללך."

# Body structure (RTL)
- Hook (line 1, max 6 words)
- Problem agitation (1-2 sentences)
- Solution + product
- Proof (review/stat/guarantee)
- CTA + urgency

# CTAs in Hebrew
- "לחץ/י למוצר" — Soft
- "הזמן/י עכשיו - משלוח חינם" — Action
- "להזמין לפני שייגמר" — Urgency
- "לראות ביקורות" — Information
```

**Rules:**
- **אסור:** ללא שימוש בסופרלטיבים שלא ניתנים להוכחה ("הטוב בעולם").

- בעברית מקצועית – לא תרגום מילולי מאנגלית.
- Hook חייב להיות בתוך 125 התווים הראשונים (Facebook truncation).
- 3-5 וריאציות לכל קמפיין ל-A/B testing.

**ערך עסקי:** העלאת CTR והורדת CPM באמצעות copy מותאם לקהל ישראלי.

### 2.4 `cvr-checklist`

**Trigger description:**
```yaml
description: Pre-publish CVR (conversion rate) safety check for any new Shopify section, product page, or landing page. Run BEFORE publishing changes. Trigger when user says "deploy", "publish", "go live", "push to production", "לפרסם", "להעלות", or commits a section file. Returns pass/fail with specific blocking issues and CVR-impact estimates.
```

**Checklist (קוד בדיקה אוטומטית ב-`scripts/cvr-check.sh`):**

```bash
#!/usr/bin/env bash
# scripts/cvr-check.sh — run from project root
set -e

FILE="$1"
ERRORS=0

echo "🔍 CVR Pre-publish check: $FILE"

# 1. RTL compliance
if ! grep -q 'dir="rtl"' "$FILE"; then
  echo "❌ Missing dir=\"rtl\" attribute"; ((ERRORS++))
fi

# 2. No physical CSS properties
if grep -qE 'margin-left|margin-right|padding-left|padding-right' "$FILE"; then
  echo "⚠️  Found physical CSS properties — use logical (margin-inline-start)"
fi

# 3. Above-fold CTA
if ! grep -qE 'class="[^"]*cta[^"]*"' "$FILE"; then
  echo "❌ No CTA class found"; ((ERRORS++))
fi

# 4. Trust signals
TRUST_PATTERNS="(משלוח חינם|החזר כספי|אחריות|ביקורות|reviews)"
if ! grep -qE "$TRUST_PATTERNS" "$FILE"; then
  echo "⚠️  No trust signals detected"
fi

# 5. Image optimization hint
if grep -qE 'src=".*\.(jpg|png)"' "$FILE" && ! grep -q 'image_url' "$FILE"; then
  echo "⚠️  Use Shopify image_url filter for responsive images"
fi

# 6. Mobile-first check
if ! grep -qE 'clamp\(|min-width:\s*768' "$FILE"; then
  echo "⚠️  No mobile-first responsive rules detected"
fi

# 7. Schema validity
if grep -q '{% schema %}' "$FILE"; then
  python3 -c "
import re, json, sys
with open('$FILE') as f: t = f.read()
m = re.search(r'\{% schema %\}(.*?)\{% endschema %\}', t, re.DOTALL)
if m:
    try: json.loads(m.group(1))
    except Exception as e: print(f'❌ Invalid schema JSON: {e}'); sys.exit(1)
"
fi

[ $ERRORS -eq 0 ] && echo "✅ All blockers passed" || { echo "❌ $ERRORS blockers"; exit 1; }
```

**ערך עסקי:** מונע באגים ב-production, שומר על CVR יציב.

### 2.7 `review-faq-generator`

**Trigger description:**
```yaml
description: Analyze product reviews (from Judge.me, Loox, Yotpo, or CSV) and auto-generate FAQ blocks for product pages in Hebrew. Trigger on "FAQ", "שאלות נפוצות", "review analysis", "ניתוח ביקורות", or when user uploads/pastes review data. **`scripts/extract-faqs.py`:**
```

```python
#!/usr/bin/env python3
"""Reads reviews CSV, clusters by topic, outputs top 5 Hebrew FAQs."""
import csv, sys, re, json
from collections import Counter

def extract_questions(reviews):
    # Hebrew question markers
    patterns = [r'האם\s+[\w\s]+\?', r'איך\s+[\w\s]+\?', r'מה\s+[\w\s]+\?']
    qs = []
    for r in reviews:
        for p in patterns:
            qs += re.findall(p, r)
    return Counter(qs).most_common(20)

with open(sys.argv[1], encoding='utf-8') as f:
    reviews = [row['body'] for row in csv.DictReader(f)]

faqs = extract_questions(reviews)
print(json.dumps(faqs, ensure_ascii=False, indent=2))
```

### 3.7 `--dangerously-skip-permissions` – מתי בטוח?

**אזהרה רשמית מ-Anthropic:** *"Only use `--dangerously-skip-permissions` in a sandbox without internet access."*

זה לא מציאותי לרוב המקרים. הגישה הפרקטית:
- **בטוח:** Docker container עם firewall שמתיר רק domains ספציפיים (Shopify, Anthropic API), גישה ל-volume מוגדר בלבד.
- **מסוכן:** Mac/Linux רגיל, ללא container.

**חלופה מומלצת (Q1 2026):** Anthropic הציגה **Auto Mode** – מסווג שמוודא פעולות מסוכנות לפני ביצוע. 0.4% false positive rate. עוצר אחרי 3 כשלים רצופים או 20 כוללים. שימוש:
```bash
claude --permission-mode auto -p "..."
```

**עוד חלופה:** allowlist מפורט ב-`.claude/settings.json`:

```python
from moviepy import VideoFileClip, TextClip, CompositeVideoClip
from moviepy.video.tools.subtitles import SubtitlesClip
import arabic_reshaper  # works for Hebrew bidi too
from bidi.algorithm import get_display

def he_text(text: str) -> str:
    """Apply bidi for RTL rendering in PIL/FFmpeg."""
    return get_display(text)  # for Hebrew, reshaping not required

generator = lambda text: TextClip(
    text=he_text(text),
    font='./assets/fonts/Heebo-Bold.ttf',
    font_size=48,
    color='white',
    stroke_color='black',
    stroke_width=3,
    method='caption',
    size=(900, None),
    text_align='center'
)

subs = SubtitlesClip("captions.srt", make_textclip=generator, encoding='utf-8')
video = VideoFileClip("raw.mp4")
final = CompositeVideoClip([video, subs.with_position(('center', 0.78), relative=True)])
final.write_videofile("output.mp4", fps=30, codec='libx264')
```

### 4.6 דוגמת קוד מלאה: clip + script עברי → UGC מוכן

`scripts/build_ugc.py`:

```python
#!/usr/bin/env python3
"""
Usage: python build_ugc.py raw.mp4 script.txt output.mp4
"""
import os, sys, subprocess, json, requests
from pathlib import Path
from moviepy import (
    VideoFileClip, AudioFileClip, TextClip, 
    CompositeVideoClip, CompositeAudioClip, concatenate_videoclips
)
from moviepy.video.fx import Resize, FadeIn, FadeOut
from bidi.algorithm import get_display

HEEBO_BOLD = "assets/fonts/Heebo-Bold.ttf"
MUSIC_PATH = "assets/music/upbeat-track.mp3"
ELEVEN_KEY = os.environ["ELEVEN_API_KEY"]
VOICE_ID = os.environ.get("ELEVEN_VOICE_ID", "JBFqnCBsd6RMkjVDRZzb")

def generate_voiceover(text: str, out: str) -> float:
    """Hit ElevenLabs API; return audio duration in seconds."""
    r = requests.post(
        f"https://api.elevenlabs.io/v1/text-to-speech/{VOICE_ID}",
        headers={"xi-api-key": ELEVEN_KEY, "Content-Type": "application/json"},
        json={
            "text": text, 
            "model_id": "eleven_v3",
            "voice_settings": {"stability": 0.5, "similarity_boost": 0.85}
        }
    )
    r.raise_for_status()
    Path(out).write_bytes(r.content)
    # ffprobe duration
    d = subprocess.check_output([
        "ffprobe", "-v", "error", "-show_entries", "format=duration",
        "-of", "default=noprint_wrappers=1:nokey=1", out
    ])
    return float(d.strip())

def script_to_segments(script: str, total_duration: float) -> list:
    """Split Hebrew script into ~3-4 word segments, time them evenly."""
    sentences = [s.strip() for s in script.replace("\n", " ").split(".") if s.strip()]
    segments = []
    for s in sentences:
        words = s.split()
        for i in range(0, len(words), 4):
            segments.append(" ".join(words[i:i+4]))
    per = total_duration / len(segments)
    return [(i*per, (i+1)*per, seg) for i, seg in enumerate(segments)]

def make_subtitle_clip(text: str, start: float, end: float, video_size):
    return (TextClip(
                text=get_display(text),
                font=HEEBO_BOLD, font_size=64,
                color='white', stroke_color='black', stroke_width=4,
                method='caption', size=(int(video_size[0]*0.85), None),
                text_align='center'
            )
            .with_start(start).with_end(end)
            .with_position(('center', 0.72), relative=True))

def build_ugc(raw_path: str, script_path: str, out_path: str):
    script = Path(script_path).read_text(encoding='utf-8')
    
    # 1. Voiceover
    vo_path = "tmp_vo.mp3"
    vo_duration = generate_voiceover(script, vo_path)
    
    # 2. Trim video to VO duration (or loop)
    video = VideoFileClip(raw_path)
    if video.duration < vo_duration:
        # loop
        loops = int(vo_duration / video.duration) + 1
        video = concatenate_videoclips([video]*loops).subclipped(0, vo_duration)
    else:
        video = video.subclipped(0, vo_duration)
    
    # 3. Resize to 1080x1920 vertical
    video = video.resized(height=1920)
    if video.w > 1080:
        x_center = video.w // 2
        video = video.cropped(x1=x_center-540, x2=x_center+540)
    
    # 4. Hook zoom in first 3 seconds
    hook = video.subclipped(0, 3).with_effects([Resize(lambda t: 1 + 0.03*t)])
    rest = video.subclipped(3, video.duration)
    video = concatenate_videoclips([hook, rest])
    
    # 5. Subtitles
    segments = script_to_segments(script, vo_duration)
    sub_clips = [make_subtitle_clip(text, start, end, (1080, 1920))
                 for start, end, text in segments]
    
    # 6. Audio mix
    vo = AudioFileClip(vo_path)
    music = AudioFileClip(MUSIC_PATH).subclipped(0, vo_duration).with_volume_scaled(0.12)
    audio = CompositeAudioClip([vo, music])
    
    # 7. Compose & render
    final = CompositeVideoClip([video, *sub_clips]).with_audio(audio)
    final.write_videofile(
        out_path, fps=30, codec='libx264',
        audio_codec='aac', preset='medium', bitrate='6000k',
        threads=4
    )
    
    # cleanup
    Path(vo_path).unlink(missing_ok=True)
    print(f"✅ UGC saved to {out_path}")

if __name__ == "__main__":
    build_ugc(sys.argv[1], sys.argv[2], sys.argv[3])
```

## Caveats — אזהרות והסתייגויות

1. **Claude Code Skills היא תכונה חדשה וזזה מהר.** המבנה (SKILL.md, YAML frontmatter, progressive disclosure) יציב נכון לתיעוד הרשמי באפריל 2026, אך פרטים כמו pricing של ElevenLabs/HeyGen, ושמות מודלים (Sonnet 4.7, Opus 4.7) משתנים. בדוק תמיד את `docs.anthropic.com` ו-`code.claude.com/docs` לפני יישום פרודקשן.

2. **Shopify MCP — Anthropic לא מספקת אחד רשמי.** ה-MCP servers של Shopify הם:
   - `shopify/dev-mcp` — רשמי **מ-Shopify** ל-development (תיעוד, validation), **לא** לניהול חנות.
   - `shopify/storefront-mcp` — רשמי **מ-Shopify**, קטלוג + סל ללקוחות, **ללא Admin API**.
   - **Admin API** — דרך MCP servers **קהילתיים** (ajackus, GeLi2001, antoineschaller). יציבים אך לא רשמיים. בדוק את הקוד.

3. **CapCut API — לא קיים API ציבורי רשמי.** הוזכר במפורש בחלק 4.2.

4. **`--dangerously-skip-permissions` הוא מסוכן.** הסיכון אמיתי (32% מהמשתמשים דיווחו על file modification לא רצוי, לפי מקור צד שלישי). השתמש רק ב-Docker container עם network policy או ב-`auto` mode החדש.

5. **`claude schedule` (Q1 2026)** — סקירה מהבלוג של Anthropic, אך בדוק זמינות בחשבונך — תכונה יחסית חדשה.

6. **Meta Ads MCP via Pipeboard** — שירות צד שלישי. ה-OAuth flow מעביר tokens דרך השרת של Pipeboard. למי שצריך שליטה מלאה, השתמש ב-`brijr/meta-mcp` (self-hosted, דורש META_ACCESS_TOKEN).

7. **MoviePy 2.x פרסום breaking changes מ-v1.** קוד ישן (`subclip` במקום `subclipped`, `set_position` במקום `with_position`) ישבר. כל הדוגמאות כאן הן ל-v2.

8. **HeyGen Hebrew quality** — תיעוד HeyGen לא מציג רשמית רשימת voice IDs בעברית. ייתכן שתצטרך לעלות Audio של voiceover מוכן (מ-ElevenLabs) במקום TTS שלהם.

9. **Hebrew bidi בכתוביות** — ספריית `python-bidi` נדרשת על מערכות שבהן FFmpeg/PIL לא מטפלים אוטומטית. בדוק שהפונט (Heebo) מותקן ומופנה לנתיב מוחלט.

10. **ה-Skills שהוצעו ב-חלק 2 הם תבניות.** הם דורשים iteration. ה-`description` ייתכן ויחייב התאמה אחרי 5-10 שימושים אמיתיים כדי שהטריגרים יעבדו בצורה אופטימלית. שמור log של מתי Claude **לא** הפעיל skill שהיה צריך, ועדכן את ה-description שיהיה יותר "pushy".

11. **CVR impact estimates ב-חלק 5 הם השערות מבוססות-ניסיון התעשייה.** התוצאות בפועל תלויות בנישה (תינוקות), בקהל (ישראלי), ב-baseline הקיים. תמיד מודד.

12. **תוכניות Anthropic vs API costs** — Claude Code זמין בתוכנית Pro ($20/mo) ו-Max ($100-200/mo) עם usage limits. לאוטומציה כבדה (cron יומי) שקול את ה-API ישירות עם budget caps (`--max-budget-usd`).
