## 6. Live Write Plan

מה ירוץ כשאייל מאשר T3:

```python
# לכל PID ברשימת 65:
existing_tags = GET /admin/api/.../products/{pid}.json  # קריאה
merged_tags   = existing_tags + shoe_tags[pid]           # append בלבד
PUT /admin/api/.../products/{pid}.json  tags=merged_tags  # כתיבה
log_result(pid, existing_tags, merged_tags)
```

**סדר ביצוע:**
1. backup (שלב 4) — חובה לפני
2. dry-run (שלב 5) — אייל מאשר פלט
3. live write — batch של 65 מוצרים
4. verify (שלב 7) — תוך 5 דקות

**Rate limit:** 2 req/sec — 65 מוצרים ≈ 33 שניות כולל GET+PUT
